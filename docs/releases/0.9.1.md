## Features 🚀

### Isometric diagrams

Run `d2 --isometric input.d2 output.svg` to draw an existing diagram from a fixed angle. In this four-color printing press, the ink fountains are cylinders, the rollers are queues, and the raised platforms are nested containers.

</a>

<a href="/img/generated/printing-press.gif">See the press in motion</a> or [try the D2 source in the Isometric guide](../tour/isometric.md#export-formats).

### Animated transitions

Set `animate-duration` to animate changes between steps. Colors blend, grid cells slide into place, and a row can unfold to show what's inside. In this example, 1,200 viewers request the same image from six edge locations. Watch the shield cache combine those requests into one origin read.

<a href="/img/generated/cache-stampede.svg" aria-label="Open the full-size cache-stampede animation">
  <img src="/img/generated/cache-stampede.svg" width="1018" height="459" style={{height: "auto"}} alt="Requests from six edge locations join a single in-flight request at the shield cache. One read reaches the origin, and the response fans back out." />
</a>

[View the animation source](../tour/animation.md), [set transition timing](../tour/animation.md#configuration), or [animate a grid](../tour/animation.md#grid-animations).

:::warning
Isometric mode and animated transitions are in alpha. Feedback and suggestions are welcome. [Open a GitHub issue](https://github.com/d2lang/d2/issues/new).
:::

### Layout and installation

- **ELK** now offers force, stress, tree, and radial layouts alongside the default layered layout. [Compare all five algorithms on the same diagram](../tour/elk.md#choose-an-algorithm).
- **Windows x64** users can install D2 for their own account without administrator rights. Choose the download ending in `-windows-amd64-user.msi`. [Windows installer options](../tour/install.md#windows)

## Improvements 🧹

### Faster SVG exports

These timings include starting the CLI, laying out the diagram, and writing the SVG on an Apple M4. The ten-diagram result sums the median time for each input. [Grid layout change](https://github.com/d2lang/d2/pull/2893) · [Ten real-world benchmark diagrams](https://github.com/d2lang/d2/blob/8568efdf/e2etests/testdata/files/REAL_WORLD.md)

| Workload | v0.9.0 | v0.9.1 candidate | Speedup |
| --- | ---: | ---: | ---: |
| 3,000 rectangles in a grid | 7.01 s | 246 ms | 28.5× |
| Ten real-world diagrams | 362 ms | 251 ms | 1.44× |

### Smaller SVGs

D2 now reuses geometry and arrowheads across animation frames and leaves unused styles out of static SVGs. These measurements compare the same inputs before and after that change, with each SVG compressed using gzip level 9. [SVG benchmarks and visual comparisons](https://github.com/d2lang/d2/pull/3030)

| Gzipped SVG | Before | After | Reduction |
| --- | ---: | ---: | ---: |
| Cache-stampede animation above, 256 frames | 144 KB | 67 KB | 54% |
| All 27 Animation guide examples | 481 KB | 333 KB | 31% |
| 947 static test diagrams combined | 8.22 MB | 7.99 MB | 2.8% |

### Smaller downloads

| Artifact | Before | After | Change |
| --- | ---: | ---: | ---: |
| D2.js npm package | 31.66 MB | 16.08 MB | 49% smaller |
| D2.js browser download (HTTP Brotli) | 8.52 MB | 6.62 MB | 22% smaller |
| Docker image layers, Linux x86-64 | 92.16 MB | 54.60 MB | 41% smaller |
| Docker image layers, Linux arm64 | 86.55 MB | 52.16 MB | 40% smaller |
| Native CLI, macOS arm64 | 40.036 MB | 40.095 MB | 0.15% larger |

The D2.js comparison uses the published `@d2lang/d2` 0.1.34 package and a build from the 0.9.1 source. The Docker figures compare compressed CI images before and after removing duplicate copies of the CLI. The native CLI comparison uses v0.9.0 and the 0.9.1 candidate. [D2.js build](https://github.com/d2lang/d2/tree/8568efdf/d2js) · [Docker measurements](https://github.com/d2lang/d2/pull/3003)

## Upgrading

- If a diagram uses images on a private network, pass `--allow-private-network` when rendering trusted input. [Network access changes](https://github.com/d2lang/d2/pull/2899)
- If you embed D2 in Go and use local imports or images, set an explicit filesystem access policy. [Go API changes and examples](https://github.com/d2lang/d2/pull/2901)
