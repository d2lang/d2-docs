- **TALA** routes larger cross-container diagrams and packs hierarchies more tightly while preserving sibling order for equivalent branches. [#2986](https://github.com/d2lang/d2/pull/2986) · [#3025](https://github.com/d2lang/d2/pull/3025)
- **Exports.** Animated SVG connections respect `prefers-reduced-motion`. Multiboard exports preserve unrelated files and user edits. [#2976](https://github.com/d2lang/d2/pull/2976) · [#2900](https://github.com/d2lang/d2/pull/2900)
- **File and image access.** Exports validate image contents and sizes. Use `--allow-private-network` for trusted internal images or `--allow-local-files=false` to disable local reads by diagrams. In Go, set `CompileOptions.FS` for imports and configure image access separately. [Go import options](https://github.com/d2lang/d2/blob/8568efdf/d2lib/d2.go#L45-L53) · [Image options](https://github.com/d2lang/d2/blob/8568efdf/lib/imageasset/imageasset.go#L368-L376)
- **Watch mode** authenticates browser sessions through the URL printed by `d2 --watch`. [#2910](https://github.com/d2lang/d2/pull/2910)
- **Installation.** Standalone installs verify SHA-256 checksums. Add `--verify-provenance` to verify signed builds locally. Source builds require Go 1.27.4 or newer. #### Bugfixes ⛑️

- **ELK.** Force, stress, and Mr. Tree route labeled self-loops. These layouts and radial attach cross-container edges to the correct shape or SQL column. Loop labels clear rounded bends where space permits. Mr. Tree routes avoid crossing intervening nodes. [#3016](https://github.com/d2lang/d2/pull/3016) · [#3017](https://github.com/d2lang/d2/pull/3017) · [#3018](https://github.com/d2lang/d2/pull/3018) · [#2981](https://github.com/d2lang/d2/pull/2981)
- **TALA.** Fixed overlapping hierarchy nodes and containers, reversed dependencies, and misplaced endpoint labels. SQL edges attach to the correct row. Routes separate at shared endpoints where space permits and stay attached when containers move. [#3022](https://github.com/d2lang/d2/pull/3022) · [#3028](https://github.com/d2lang/d2/pull/3028) · [#3031](https://github.com/d2lang/d2/pull/3031) · [#2889](https://github.com/d2lang/d2/pull/2889)
- **SVG.** Stroke gradients continue through arrowheads. Link and tooltip numbering matches the appendix, including in animated frames. Scaled exports retain their size with footnotes. SVG text, attributes, links, paint values, and IDs are validated or escaped as appropriate. [#3020](https://github.com/d2lang/d2/pull/3020) · [#2962](https://github.com/d2lang/d2/pull/2962) · [#2964](https://github.com/d2lang/d2/pull/2964) · [#2919](https://github.com/d2lang/d2/pull/2919)
- **Native exports.** SVG icons render with gradients, masks, and blur. PDF backgrounds fill the margins on pages without navigation. PNG watch previews embed local images and show placeholders for missing images. [#2982](https://github.com/d2lang/d2/pull/2982) · [#2932](https://github.com/d2lang/d2/pull/2932) · [#2980](https://github.com/d2lang/d2/pull/2980)
- **Labels.** SQL and class members retain types that match their names. Fixed LaTeX font colors, paired delimiters, and `bigtimes`. ASCII aligns multibyte labels and keeps arrowheads visible under long labels. [SQL tables](../tour/sql-tables.md) · [UML classes](../tour/uml-classes.md) · [ASCII export](../tour/exports.md#ascii)
- **Compiler and API.** Parsing and compilation honor cancellation, including before `d2 fmt` writes. Cyclic variables, oversized expansions, invalid board trees, and oversized grids return errors. Go callers can configure expansion budgets. [Compiler and renderer limits](https://github.com/d2lang/d2/blob/8568efdf/ci/release/changelogs/next.md#L69)
- **D2.js.** Fixed Safari worker startup, custom TrueType fonts supplied as `Uint8Array`, and cleanup of generated worker URLs. [#2965](https://github.com/d2lang/d2/pull/2965) · [#3007](https://github.com/d2lang/d2/pull/3007) · [#3013](https://github.com/d2lang/d2/pull/3013)
- **Windows and standalone installs.** Nested imports resolve relative to the importing file, including on UNC shares. Git Bash can acquire the installer lock. Failed upgrades preserve the existing install. [#2993](https://github.com/d2lang/d2/pull/2993) · [#3026](https://github.com/d2lang/d2/pull/3026) · [#3024](https://github.com/d2lang/d2/pull/3024)

#### Breaking Changes

- **Layout plugins and postprocessing.** D2 no longer loads external `d2plugin-*` executables. Use a built-in engine. The Go `d2plugin` package was removed. To replace `PostProcess`, modify the bytes returned by `d2svg.Render`. [Layout engines](../tour/layouts.md#layout-engines) · [Go example](https://github.com/d2lang/d2/blob/8568efdf/docs/examples/lib/1-d2lib/d2lib.go#L28-L35)
