#### Features 🚀

- **Isometric diagrams.** Run `d2 --isometric input.d2 output.svg` to draw an existing diagram from a fixed angle. The CLI exports SVG, PNG, GIF, PDF, and PPTX. You can also enable isometric mode in D2 source or through the Go and JavaScript APIs. In this four-color printing press, the ink fountains are cylinders, the rollers are queues, and the raised platforms are nested containers. [#2881](https://github.com/d2lang/d2/pull/2881)

<a href="/img/generated/printing-press.svg" aria-label="Open the full-size isometric printing press">
  <img src="/img/generated/printing-press.svg" width="1610" height="1020" style={{height: "auto"}} alt="Four ink fountains feed cyan, magenta, yellow, and black rollers. The paper path runs through all four rollers to a finished color proof." />
</a>

<a href="/img/generated/printing-press.gif">See the press in motion</a> or [try the D2 source in the Isometric guide](../tour/isometric.md#export-formats).

- **Animated transitions.** Set `animate-interval` in the diagram to choose how long each board is on screen. Set `animate-duration` to spend part of that interval transitioning. SVG and GIF exports can interpolate numeric styles, solid colors, and gradient stops across steps. The default transition duration is zero. [Configure timing](../tour/animation.md#configuration) · [#3008](https://github.com/d2lang/d2/pull/3008) · [#3006](https://github.com/d2lang/d2/pull/3006)
- **Grid and sketch animations.** Grid cells slide when reordered, grow or shrink as rows change, and can unfold into a nested grid. Underlines and strikethroughs draw or retract, and sketch fills shade in or erase across steps, layers, and scenarios. [Grid examples](../tour/animation.md#grid-animations) · [Pencil shading](../tour/animation.md#pencil-shading) · [#3021](https://github.com/d2lang/d2/pull/3021) · [#3029](https://github.com/d2lang/d2/pull/3029)

In this example, 1,200 viewers request the same image from six edge locations. Watch the shield cache combine those requests into one origin read. [View the D2 source](../tour/animation.md).

</a>

:::warning
Isometric mode and animated transitions are in alpha. Feedback and suggestions are welcome. [Open a GitHub issue](https://github.com/d2lang/d2/issues/new).
:::

- **ELK layouts.** You can now set `elk-algorithm` in the diagram to select layered, force, stress, Mr. Tree, or radial layout. Layered layout gains controls for merging and routing edges, wrapping long runs, and placing a shape in the first or last layer. New options for the other layouts include force repulsion, stress edge length, tree sibling order, and radial spacing. [Compare all five layouts](../tour/elk.md#choose-an-algorithm) · [Layered options](../tour/elk.md#layered-layout-options) · [#2887](https://github.com/d2lang/d2/pull/2887) · [#2981](https://github.com/d2lang/d2/pull/2981)
- **Diagram configuration.** Set `scale` and `force-appendix` in `vars.d2-config`. Set `dagre-nodesep` and `dagre-edgesep` in `vars.d2-config.data` to control the spacing between Dagre nodes and edges. [Scale and appendix](../tour/vars.md#output-scale-and-svg-appendix) · [Dagre spacing](../tour/dagre.md#spacing) · [#3012](https://github.com/d2lang/d2/pull/3012)
- **Connection crossings.** D2 leaves a small transparent gap in the back line where connections cross. The gap scales with stroke width and works on colored and transparent backgrounds. [#3011](https://github.com/d2lang/d2/pull/3011)
- **Windows x64 installer.** Choose the download ending in `-windows-amd64-user.msi` to install D2 for your account without administrator rights. The machine-wide MSI is still available. [Windows installer options](../tour/install.md#windows) · [#2975](https://github.com/d2lang/d2/pull/2975)
- **D2.js.** The next npm release adds `d2.renderSVG()` for rendering source or a multi-file project in one call, and `d2.format()` for formatting source without laying it out. You can construct D2 inside a dedicated browser worker or supply a self-hosted worker with `new D2({ workerURL })`. The TypeScript declarations now cover theme overrides and the existing Playground link methods, `encode` and `decode`. [JavaScript API](https://github.com/d2lang/d2/tree/8568efdf/d2js/js#api-reference) · [#2953](https://github.com/d2lang/d2/pull/2953) · [#3004](https://github.com/d2lang/d2/pull/3004) · [#3007](https://github.com/d2lang/d2/pull/3007) · [#3009](https://github.com/d2lang/d2/pull/3009) · [#3014](https://github.com/d2lang/d2/pull/3014)

#### Improvements 🧹

**CLI export times**

These timings include starting the CLI, laying out the diagram, and writing the SVG on an Apple M4. The ten-diagram result sums the median time for each input. The native layout timings sum the time spent inside each engine across D2's end-to-end diagrams on an Apple M4. Each Dagre and ELK layout matched that engine's previous output. A few TALA layouts changed. [#2999](https://github.com/d2lang/d2/pull/2999)

**Layout, exports, and installation**

- **TALA** can route larger diagrams within its existing search budget. A diagram with 40 containers and 100 connections that previously hit the limit now renders with all three default seeds. Hierarchies use less space, center symmetric branches, and keep interchangeable siblings in declaration order as you add branches. [#2986](https://github.com/d2lang/d2/pull/2986) · [#3025](https://github.com/d2lang/d2/pull/3025)
- **Accessibility.** Animated SVG connections respect the viewer's `prefers-reduced-motion` setting. [#2976](https://github.com/d2lang/d2/pull/2976)
- **Multiboard exports** write the new boards together, keep output paths inside the selected directory, and preserve unrelated files and user edits on subsequent exports. [#2900](https://github.com/d2lang/d2/pull/2900) · [#2908](https://github.com/d2lang/d2/pull/2908)
- **Images and watch mode.** SVG and raster exports apply the same local-file and network policies and share limits on image downloads and decoding. Use `--allow-local-files=false` to disable diagram-initiated local imports and image reads. Watch mode authenticates its HTTP and WebSocket connections. Open the URL printed by the current process to start the browser session. [#2911](https://github.com/d2lang/d2/pull/2911) · [#2918](https://github.com/d2lang/d2/pull/2918) · [#3002](https://github.com/d2lang/d2/pull/3002) · [#2910](https://github.com/d2lang/d2/pull/2910)
- **Standalone installs** verify archives against reviewed SHA-256 checksums before extraction. Pass `--verify-provenance` to verify signed build provenance locally as well. [Installer verification](https://github.com/d2lang/d2/blob/8568efdf/docs/INSTALL.md#security) · [#3023](https://github.com/d2lang/d2/pull/3023)
- **Builds and releases.** D2 updates its Go toolchain and dependencies. CI builds its formatter from the checkout and verifies the Pandoc package. npm releases build from a clean source tree and protect the publishing token during local release builds. [#2994](https://github.com/d2lang/d2/pull/2994) · [#2913](https://github.com/d2lang/d2/pull/2913) · [#2914](https://github.com/d2lang/d2/pull/2914) · [#2886](https://github.com/d2lang/d2/pull/2886) · [#2915](https://github.com/d2lang/d2/pull/2915)

#### Bugfixes ⛑️

- **ELK**
  - Force, stress, and Mr. Tree correctly route labeled and multiple self-loops on one shape. Loop labels move clear of rounded bends when space permits. [#3016](https://github.com/d2lang/d2/pull/3016) · [#3017](https://github.com/d2lang/d2/pull/3017)
  - Force, stress, Mr. Tree, and radial route connections across container boundaries to the intended shape or SQL column. Mr. Tree also avoids doubling back into a target or taking a shortcut through another node. [#3018](https://github.com/d2lang/d2/pull/3018) · [#2981](https://github.com/d2lang/d2/pull/2981)
- **TALA**
  - Hierarchies keep nodes on the same rank and neighboring containers from overlapping. Nested hierarchies respect their direction, container dimensions, and proximity hints. Mixing undirected links or cycles with directed dependencies preserves the direction of those dependencies. [#3022](https://github.com/d2lang/d2/pull/3022)
  - Connections entering the same shape use separate arrowhead positions when space permits. Self-loops clear neighboring ranks, and parallel and reciprocal connections leave room for endpoint labels, including on left-pointing arrows. [#3028](https://github.com/d2lang/d2/pull/3028)
  - SQL references and self-references attach to the correct rows. In ordinary and grid diagrams, routes separate where space permits, clear endpoint labels, and avoid unnecessary trips out of and back into a container. #### Breaking Changes

- **External layout engines.** The CLI runs the built-in Dagre, ELK, and TALA engines. If you selected a separately installed layout executable, choose a built-in engine. The legacy Go layout protocol and render postprocessing hooks have been removed. [Layout engines](../tour/layouts.md#layout-engines) · [#2897](https://github.com/d2lang/d2/pull/2897) · [#2920](https://github.com/d2lang/d2/pull/2920)
- **Network images.** Remote image fetching blocks private and reserved destinations by default. If a trusted diagram needs images from an internal server, pass `--allow-private-network` or set `D2_ALLOW_PRIVATE_NETWORK`. Bundling accepts valid PNG, JPEG, GIF, WebP, or SVG images and checks their contents. [#2899](https://github.com/d2lang/d2/pull/2899) · [#2898](https://github.com/d2lang/d2/pull/2898) · [#2918](https://github.com/d2lang/d2/pull/2918)
- **Local files in Go.** Set `CompileOptions.FS` to the filesystem that contains your imports. Configure local image access separately when bundling or rendering images. The CLI and watch mode continue to allow local files by default. [Go import options](https://github.com/d2lang/d2/blob/8568efdf/d2lib/d2.go#L45-L53) · [Image options](https://github.com/d2lang/d2/blob/8568efdf/lib/imageasset/imageasset.go#L368-L376) · [#2901](https://github.com/d2lang/d2/pull/2901)
- **Large inputs.** Some inputs that previously ran until they exhausted memory now return an error at a defined limit.
  - Source allows 128 nested map/array levels and 128 imports in one active chain. Decoded Playground source is capped at 16 MiB. A LaTeX label can contain up to 4 KiB and 128 nested groups. [#2894](https://github.com/d2lang/d2/pull/2894) · [#2904](https://github.com/d2lang/d2/pull/2904) · [#2902](https://github.com/d2lang/d2/pull/2902) · [#2922](https://github.com/d2lang/d2/pull/2922)
  - Each declared grid dimension is capped at 10,000. A single grid permits up to 1,000,000 cells, including empty slots when both dimensions are given. Each graph passed to Dagre or ELK permits up to 1,024 objects and 1,024 edges, with a separate limit for densely connected inputs. D2 lays out grid cells separately, including the 3,000-rectangle example above. [#2924](https://github.com/d2lang/d2/pull/2924) · [#2926](https://github.com/d2lang/d2/pull/2926)
  - Rendered board trees allow up to 1,024 levels below the root and 16,384 boards. [#2912](https://github.com/d2lang/d2/pull/2912)
- **Source builds** require Go 1.27.4 or newer. [Build from source](https://github.com/d2lang/d2/blob/8568efdf/docs/INSTALL.md#from-source) · [Contributor setup](https://github.com/d2lang/d2/commit/7dd2b6a1c25e6a7ac46536553ce832b9f0511797) · [#2994](https://github.com/d2lang/d2/pull/2994)
