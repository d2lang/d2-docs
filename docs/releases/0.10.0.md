- **Language server.** Run `d2 lsp` for live diagnostics, completion, and formatting in your editor. Go to definition, find references, and rename shapes across open diagrams and their imports. [Editor setup](https://github.com/d2lang/d2/blob/d70ec718/docs/LSP.md)
- **MCP server.** Run `d2 mcp` to let an AI client look up D2 syntax, check diagrams, and render PNG, SVG, or text. [Set up Codex or Claude Code](../tour/mcp.md)
- **ELK.** Set `elk-algorithm` in the diagram. New options control edge routing, layer placement, tree ordering, and spacing. [Compare algorithms](../tour/elk.md#choose-an-algorithm) · [Layered options](../tour/elk.md#layered-layout-options)
- **Configuration.** Set `scale` and `force-appendix` in `vars.d2-config`, and `dagre-nodesep` and `dagre-edgesep` in `vars.d2-config.data`. [Export options](../tour/vars.md#output-scale-and-svg-appendix) · [Dagre spacing](../tour/dagre.md#spacing)
- **Connections.** Crossing lines now leave a transparent gap in the back line where there’s room. [#3011](https://github.com/d2lang/d2/pull/3011)
- **Themes.** Select light and dark themes by name, for example `theme-id: Terminal` or `--dark-theme dark-mauve`. [Themes](../tour/themes.md)
- **Syntax.** Use unquoted labels like `cost $5` and `#oncall`, colors like `#abc`, and names like `R&D`. Variables can use keyword names, and nested shapes can be named `layers`, `scenarios`, or `steps`. [Punctuation](https://github.com/d2lang/d2/pull/3054) · [Hash-prefixed labels and keyword names](https://github.com/d2lang/d2/pull/3056)
- **Formatter.** `d2 fmt README.md` formats D2 fences in Markdown. Use `d2 fmt --check --diff README.md` to show a diff in CI. [Formatter options](https://github.com/d2lang/d2/pull/3052)
- **Installation.** Run the CLI with `uvx d2lang`, or install it in CI with `d2lang/setup-d2@v1`. Windows x64 now has a `-user.msi` installer for users without administrator rights. [uv and uvx](https://github.com/d2lang/d2/blob/d70ec718/docs/INSTALL.md#uv-and-uvx) · [GitHub Actions](https://github.com/d2lang/d2/blob/d70ec718/docs/INSTALL.md#github-actions) · [Windows](../tour/install.md#windows)
- **D2.js 0.2.0.** Render source directly with `d2.renderSVG()`, format it with `d2.format()`, or run D2 in a dedicated or self-hosted worker. TypeScript definitions now cover theme overrides and Playground link encoding. Try nightly builds with `npm install @d2lang/d2@nightly`. [JavaScript API](https://github.com/d2lang/d2/tree/d70ec718/d2js/js#api-reference)
- **Language reference.** Explore the grammar with railroad diagrams, EBNF, and parser conformance cases. Download the docs as Markdown, by page or in one file. [Grammar reference](../tour/grammar.md) · [Conformance cases](https://github.com/d2lang/d2/tree/d70ec718/docs/grammar/testdata) · [Page index](https://d2lang.com/llms.txt) · [Full text](https://d2lang.com/llms-full.txt)

#### Bugfixes ⛑️

- **ELK.** Force, stress, and Mr. Tree route labeled self-loops. These layouts and radial attach cross-container edges to the correct shape or SQL column. Loop labels clear rounded bends where space permits. Mr. Tree routes avoid crossing intervening nodes. [#3016](https://github.com/d2lang/d2/pull/3016) · [#3017](https://github.com/d2lang/d2/pull/3017) · [#3018](https://github.com/d2lang/d2/pull/3018) · [#2981](https://github.com/d2lang/d2/pull/2981)
- **TALA.** Fixed overlapping nodes and captions, reversed dependencies, and misplaced endpoint labels. Chains of `step` shapes retain connection order and annotations. Pinned junctions stay in place. SQL edges attach to the correct row, and routes stay attached when containers move. [#3032](https://github.com/d2lang/d2/pull/3032) · [#3022](https://github.com/d2lang/d2/pull/3022) · [#3028](https://github.com/d2lang/d2/pull/3028) · [#3031](https://github.com/d2lang/d2/pull/3031) · [#2889](https://github.com/d2lang/d2/pull/2889)
- **Grids.** Cells keep their order through imports and variable spreads. Circles stay round, nested content fits, and routes retain SQL row targets and make room for self-loops. [Grid connections](../tour/grid-diagrams.md#connections) · [#3036](https://github.com/d2lang/d2/pull/3036)
- **Sequence diagrams.** A nested group containing only a note now renders. [Sequence groups](../tour/sequence-diagrams.md#groups) · [#3035](https://github.com/d2lang/d2/pull/3035)
- **SVG.** Stroke gradients continue through arrowheads. Link and tooltip numbering matches the appendix, including in animated frames. Board changes switch the drawing, links, and keyboard targets together. Scaled exports retain their size with footnotes. SVG text, attributes, links, paint values, and IDs are validated or escaped as appropriate. [#3020](https://github.com/d2lang/d2/pull/3020) · [#2962](https://github.com/d2lang/d2/pull/2962) · [#2964](https://github.com/d2lang/d2/pull/2964) · [#2919](https://github.com/d2lang/d2/pull/2919)
- **Native exports.** SVG icons render with gradients, masks, and blur. PDF backgrounds fill the margins on pages without navigation. PNG watch previews embed local images and show placeholders for missing images. [#2982](https://github.com/d2lang/d2/pull/2982) · [#2932](https://github.com/d2lang/d2/pull/2932) · [#2980](https://github.com/d2lang/d2/pull/2980)
- **Labels.** SQL and class members retain types that match their names. Fixed LaTeX font colors, paired delimiters, and `bigtimes`. ASCII aligns multibyte labels and keeps arrowheads visible under long labels. [SQL tables](../tour/sql-tables.md) · [UML classes](../tour/uml-classes.md) · [ASCII export](../tour/exports.md#ascii)
- **Syntax.** Unquoted reserved keys ignore case. Quote `"STYLE"` for an object name. Labels like `10${unit}` interpolate correctly. Undirected edges require `--`, block fences must match, and invalid groups, indices, filters, and paths report errors. `d2 fmt` preserves board order, import filename case, escapes, and empty maps. `d2 fmt -` writes already-formatted stdin to stdout. [Formatter](../tour/auto-formatter.md) · [Syntax fixes](https://github.com/d2lang/d2/pull/3043)
- **Variables.** Map spreads apply where they appear, so later assignments win. Templates keep their declaration scope and can style existing connections. Forward references resolve fully, glob filters see substituted values, and Markdown uses the nearest variable binding, including in link URLs and titles. [Markdown variables](https://github.com/d2lang/d2/pull/3057) · [Variable fixes](https://github.com/d2lang/d2/pull/3060) · [Spread substitutions](../tour/vars.md#spread-substitutions) · [#3044](https://github.com/d2lang/d2/pull/3044)
- **Compiler and API.** Parsing and compilation honor cancellation, including before `d2 fmt` writes. Cyclic variables, oversized expansions, invalid board trees, and oversized grids return errors. Go callers can configure expansion budgets. [Compiler and renderer limits](https://github.com/d2lang/d2/blob/d70ec718/ci/release/changelogs/next.md#L108-L158)
- **D2.js.** Fixed Safari worker startup, custom TrueType fonts supplied as `Uint8Array`, and cleanup of generated worker URLs. [#2965](https://github.com/d2lang/d2/pull/2965) · [#3007](https://github.com/d2lang/d2/pull/3007) · [#3013](https://github.com/d2lang/d2/pull/3013)
- **Windows and standalone installs.** Nested imports resolve relative to the importing file, including on UNC shares. Git Bash can acquire the installer lock. Failed upgrades preserve the existing install. [#2993](https://github.com/d2lang/d2/pull/2993) · [#3026](https://github.com/d2lang/d2/pull/3026) · [#3024](https://github.com/d2lang/d2/pull/3024)

#### Breaking Changes

- **Layout plugins and postprocessing.** D2 no longer loads external `d2plugin-*` executables. Use a built-in engine. The Go `d2plugin` package was removed. To replace `PostProcess`, modify the bytes returned by `d2svg.Render`. [Layout engines](../tour/layouts.md#layout-engines) · [Go example](https://github.com/d2lang/d2/blob/d70ec718/docs/examples/lib/1-d2lib/d2lib.go#L28-L35)
