# Obsidian plugin

In **Settings → Community plugins → Browse**, search for **D2**, then install
and enable it. The official plugin bundles D2.js and works offline on desktop
and mobile.

Write a fenced `d2` block in a note to render it in Live Preview or Reading
view. To format the source, place the cursor inside the block and run
**D2: Format D2 Block**. Select **Save SVG** below the diagram to save it as
an attachment.

Diagrams can import `.d2` files in the vault. For example, `...@shared`
loads `shared.d2` beside the note.
