# Synthwave City

A neon city skyline doubles as an event-driven architecture, with cloud towers, an underground event train, and an all-night arcade.

Three unequal districts and nested vertical towers create a skyline, with magenta application paths and cyan transport paths.

All icon SVGs are original vector artwork made for this fictional example. The rendered SVG embeds the icons; the D2 source uses the adjacent icons directory.

Render with the public D2 build documented in the collection manifest:

```sh
d2 --layout tala --tala-seeds 1,2,3 --theme 0 --pad 40 --scale 1 --layout tala --tala-seeds 1,2,3 --theme 0 --pad 40 --scale 1 source.d2 tala.svg
```
