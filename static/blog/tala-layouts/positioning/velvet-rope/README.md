# Velvet Rope

A zero-trust hotel with an identity concierge, nested security floors, short-lived room keys, and an audited data vault.

Black, warm cream and muted gold turn a sectional architecture diagram into a luxury editorial spread.

All icon SVGs are original vector artwork made for this fictional example. The rendered SVG embeds the icons; the D2 source uses the adjacent icons directory.

Render with the public D2 build documented in the collection manifest:

```sh
d2 --layout tala --tala-seeds 1,2,3 --theme 0 --pad 40 --scale 1 source.d2 tala.svg
```
